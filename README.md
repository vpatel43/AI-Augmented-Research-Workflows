# AI-Augmented Research Workflows

Two companion sites for the InnovateED workshop "Using AI to Enhance Your Research Workflow" (Lane Medical Library, Stanford Medicine, 7 October 2026).

- **[What do you mean, research?](https://vpatel43.github.io/AI-Augmented-Research-Workflows/arc-origins/)** The opening segment: how the eight-phase research arc was built, by researching research.
- **[Convergence Explorer](https://vpatel43.github.io/AI-Augmented-Research-Workflows/)** Seven questions about research, answered with no sources and with each AI search tool, and a measure of how far the answers converge.

This repository holds the built sites, served by GitHub Pages from the `main` branch. Add `?present=1` to either address for presenter mode.
